# Product Mission

## Problem

The family needs a centralized way to manage a private domestic book library, including the current inventory and future books that need to be acquired.

## Target Users

My family.

## Solution

A responsive web application that lets family members add books quickly using a phone camera or uploaded images to capture covers, ISBN barcodes, or numbers. It includes a wishlist, tagging, and other useful organization features to make the library easy to browse and maintain from both mobile and desktop devices.
