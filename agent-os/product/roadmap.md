# Product Roadmap

## Phase 1: MVP

- Manage books with full CRUD operations
- Attach cover images to books
- Wishlist for books to acquire
- Basic search across the collection
- Tagging support
- Responsive layout optimized for both mobile phone and desktop browser

## Phase 2: Post-Launch

- Add books by photo / ISBN barcode / number capture
- Complex search and filtering
- Author details and management
- Import / export of library data
